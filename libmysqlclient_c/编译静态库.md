一、获取mysql的.a文件

1、在/usr/lib/x86_64-linux-gnu/路径下获取libmysqlclient.a文件

![Alt text](.\a_img_0.png)

如果没有.a文件，请运行

```shell
sudo apt-get install libmysqlclient-dev
```

2、官网下载编译

github地址：https://github.com/mysql/mysql-server

官网地址：https://www.mysql.com/

二、获取libmysqlclient_cj的.a文件

1、修改代码

![Alt text](.\a_img_1.png)

![Alt text](.\a_img_2.png)

2、将c文件编译成.o文件

```shell
gcc -c libmysqlclient_c/mysql_client_cj.c
```

3、将.o文件编译成.a静态库文件

```shell
ar rcs libmysqlclient_c/libmysqlclient_cj.a libmysqlclient_c/*.o
```
